===RULES===
1. Output exactly one line containing only the final instruction — no headings, labels, reasoning, quotes, or any other text. Never output the words "Thinking Process".
2. Rewrite the instruction as a short, plain imperative that keeps the same objects and goal.
3. Delete politeness, requests, and framing ("please", "could you", "I would be grateful", "I need you to", "make sure", "for me") and delete precondition clauses ("if the small box is empty", "provided that", "assuming"); state the action directly instead of the resulting state ("make sure the box is closed" → "close the box"; "move the bowl so it is no longer on the plate" → "take the bowl off the plate").
4. When an object is described rather than named, or named with an uncommon word, call it by its plain everyday name, and drop the description's adjectives instead of carrying them over: "the hemispherical dish intended for liquids" → "the bowl"; "the tall boiling vessel" → "the pot", not "the tall boiling pot"; "carton" → "box"; "washbasin" → "sink". Also write "top" for "upper" and "bottom" for "lower".
5. Keep every object, source, destination, landmark, and either/or choice the instruction states — "in the pot or pan" stays "in the pot or pan", "from the basket" stays, "the pot that's resting in the sink" stays — and never add a colour, size, material, location, or object the instruction does not state.
6. Drop colour, size, and material words that modify a specific noun ("the orange cup" → "the cup", "the purple beet" → "the beet", "the green plate" → "the plate"); keep them when the noun is vague ("the red object", "the blue figure", "the green thing").
7. Use plain manipulation verbs: move, put, place, take, pick up, open, close, fold, unfold, turn, push, pull, lift, flip, remove, set, grab. Replace ornate verbs ("transfer", "relocate", "deposit", "convey", "hoist", "grip", "reorient", "elevate") with the closest one from that list, and never replace a verb that is already plain.
8. If the instruction tells the robot to move its own hand, gripper, or arm from one object to another while carrying nothing, write it as "end effector transition from X to Y" with the stated X and Y ("Transfer the robot hand from the first piece to the second one." → "end effector transition from the first piece to the second one").
9. Apply only the changes these rules call for and keep the rest of the wording as it is; if no rule calls for any change, output the instruction exactly as given.

**Diagnosis of the regression.** The 7-rule book beat the 1-rule book on train (+0.415 vs +0.102) but lost on validation (6.2502 vs 6.3097, both over an unrephrased 5.711 — so +0.540 vs +0.599).
