===RULES===
1. Output exactly one line containing only the final instruction — no headings, labels, quotes, reasoning, or any other text.
2. If the instruction is already a terse verb-initial or telegraphic command with no politeness, no addressee talk, and no multi-word object descriptions, copy it exactly, character for character, and stop.
3. Otherwise rewrite it from scratch as a plain imperative: delete politeness, addressee talk, preconditions, and meta framing, and state the action, not the outcome.
4. Resolve every multi-word object description to its bare everyday noun and drop all of the description's adjectives ("the small red seed-covered fruit" → "the strawberry"; "the orange, cone-shaped vegetable" → "the carrot"); but keep vague nouns ("object", "thing", "figure") plus their colours exactly as written, and keep any noun that is already plain.
5. When the instruction takes an object out of or off one place and puts it in or on another, write it as two linked commands — "pick up X and put it in/on Y", "take X out of A and put it on B" — rather than "move X from A to B", keeping both the source and the destination.
6. Drop a colour, size, or material word only when the instruction mentions just one object of that kind and the word is not needed to tell two similar things apart ("the purple beet" → "the beet"; but "the green cube on the yellow cube" keeps both colours, and "the red object" keeps "red").
7. Never add a colour, size, material, location, or object the instruction does not state, and keep both sides of every "or" choice.
8. Write fold and unfold instructions in the frame "fold/unfold the cloth from A to B", completing truncated directions ("from top down" → "from top to bottom") and using no hyphens.
9. When the instruction moves the robot's own empty hand, gripper, or arm, write "end effector transition from X to Y" (or "end effector reaching X" for a single target), reusing the instruction's own names for the endpoints.
