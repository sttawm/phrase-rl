===RULE NOTES===
1. **Adherence: partial, and the partial matters — the applier obeyed "imperative," half-obeyed "short," and systematically broke "keeps the same objects."** First, the prior defect is gone: unlike the earlier draw of this same iter_00 (where every output was the literal string "Thinking Process:" and the −2.801 anchor was meaningless), all 40 samples are now unique, real rewrites, so this −0.399 is a valid measurement of the book. Clause by clause: imperative form is near-universal (39/40; one rewrite keeps a conditional lead-in, "Assuming the current step needs closing, …"). "Short" was obeyed only where the base was bloated — across the sample the rewrite is *longer* than the base in 22/40 cases and shorter in just 9, because the applier pads clean instructions with scene-derived attributes ("Place the purple toy eggplant on the light-green toy plate", "place silver fork from gray plastic cutlery basket to black and white utensil tray"). "Keeps the same objects" is broken in two distinct ways: attribute addition/re-grounding (colors, materials, "toy" — in most clean-base rewrites), and outright identity or synonym swaps — orange cloth→yellow cloth (twice), pan→pot, sweet potato→"yellow toy potato", clothes→"fabric", lid/pot→"metallic cover on the metallic vessel", plus one invented, goal-contradicting location ("Grab the red spatula on the front-left burner" for an object stated to be in the pot). "Plain" mostly holds, with thesaurus lapses ("unclosed washing machine", "unoccupied silver container").

   **Performance: the rule's intent is validated exactly where its precondition holds, and the book's −0.399 comes from applying it where it doesn't.** Book delta −0.399 (6.010 vs 6.408); sample mean −0.112, 14/40 positive. Split by base quality and the story is clean: on verbose/degraded bases (base logit < 5, n=10) the rule fired as written — compress to a plain imperative — and gained **+2.242** on average (e.g. the obfuscated spatula instruction +4.71, "pick up pot from sink" +3.86, box-flaps +3.05). On already-clean bases (base ≥ 5, n=30) it lost **−0.897** on average, and the loss tracks the disobedience: clean-base rewrites that got *longer* (21/30) average −1.215, while the few not lengthened average only −0.156. Worst case −5.93 ("Please take the spatula off the plate…" 7.58 → "Pick up the green spatula from the pink plate and place it in the gray sink basin" 1.65). A second pattern cuts across both halves: the biggest wins landed near the task's canonical phrasing ("Pick up the silver pot from the sink" ≈ task "pick up pot from sink", +3.86; "Shut the cardboard flap" ≈ "close brown1fbox flap", +1.63), and big losses drifted off canonical verbs/nouns ("unfold"→"Pull … from the bottom fold" −3.07, "sweet potato"→"yellow toy potato" −3.45, "pan"→"pot" −2.39). There is no per-rule number and with one rule the book delta is the closest thing to one, but it aggregates two opposite-signed regimes, so the −0.399 alone misstates both.

   **What to do.** Keep the rule — its +2.24 on the degraded tail is real earned value — and fix the two failure modes with wording, since both are clause-level. First, add a guard so the rule stops firing where it only bleeds: append "If the instruction is already a short plain imperative, return it unchanged." The clean-base regime is 75% of the sample at −0.897; verbatim return converts that to ~0 by construction. Second, replace "keeps the same objects" — which the applier read as license to re-ground objects against the scene — with an explicit ban on embellishment: "use the same plain object names and the same action verb as the instruction; do not add colors, materials, or qualifiers like 'toy' that the instruction does not contain, and do not substitute synonyms." Keep one carve-out, because scene grounding did pay precisely when the base named no objects ("robot hand from the first piece to the second one" → "from the orange cup to the silver colander", +1.51): "only if the instruction does not name an object, name the visible object plainly." Do not drop the rule; the evidence that would justify dropping it is a controlled run showing the compress-verbose-bases regime itself scoring ≤0, and this sample shows the opposite. What I would want measured in isolation before the next book: (a) the guard clause alone (always-rewrite vs return-if-clean) — that experiment settles most of the −0.399; (b) attribute addition alone on clean bases (same rewrite with and without colors) — settles whether the padding or the synonym drift is the poison, which this sample confounds. One corpus flag, unchanged from before: the pair task "put corn in pan which is on stove" / base "place the orange carrot inside the empty pot" is mislabeled and pollutes that task's deltas.

===SUGGESTIONS===
Verbatim pass-through on clean bases — score the base returned unchanged (base_logit_same_draw is false throughout, so this also calibrates redraw noise): tells us the true floor the guard clause would achieve and whether the −0.156 for non-lengthened clean rewrites is just noise.
Attribute-pair test — same episode, "pick up the spatula from the plate and put it in the sink" vs "pick up the green spatula from the pink plate and place it in the gray sink basin": isolates whether added visual attributes alone caused the −5.93-class losses.
"toy" qualifier pair — "put the eggplant on the plate" vs "put the toy eggplant on the plate": the applier inserts "toy" constantly; one cheap pair says whether it is neutral or a steady tax.
Canonical-verb restoration — on an unfold task, identical rewrite with "unfold" vs "spread"/"smooth"/"pull": tests the hypothesis that proximity to the task's canonical verb, not brevity per se, drives the big wins.
Grounding-when-vague pair — on the "end effector transition" style base, "move the gripper from the first object to the second" vs "move the gripper from the orange cup to the silver colander": tells us whether naming visible objects pays only when the base names none, which is the carve-out the revised rule depends on.
Color-correction pair — cloth episode where the base says "orange" but the visible cloth is yellow: "unfold the orange cloth…" vs "unfold the yellow cloth…": the sample contains this swap twice with opposite outcomes (−3.07, +0.09), and a controlled pair would settle whether correcting a wrong base color helps or hurts.
