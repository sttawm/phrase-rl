===RULES===
1. Apply rules 2 to 12 in numbered order, each to the output of the one before. A rule changes only the words it names and copies every other word verbatim, so an instruction that no rule fires on is output unchanged; there is no separate leave-alone condition, and every word (turn on, onto, silver, burner, cup, dish and all others) is governed only by the rule that names it. No rule adds, removes, merges, reorders or splits steps or clauses, changes how many objects are acted on, or turns a single "put X on Y" into "pick up X and place it on Y" or the reverse; a compound instruction stays one sentence with its clauses in the user's order, and each rule is applied inside every clause.
2. Resolve each noun phrase that names an object (the thing to be picked up or moved, a landmark it is next to / on / in, or the surface, holder or container it goes to) against the objects listed in the scene description, ignoring "the" / "that": (a) if the phrase is already the name of a scene object, leave it; (b) otherwise list the scene objects it could denote — objects for which the phrase is a container, packaging or category word (bottle, can, tin, jar, carton, box, cup, drink, sauce, condiment, snack, food, item, thing, container), a shortened form of the object's name (juice for orange juice, sauce for tomato sauce, soup for alphabet soup), an everyday synonym (stand for rack, coffee pot or espresso pot for moka pot, cup for mug, wine jug for wine bottle, dish for bowl), or the same kind noun with a colour word that is a shade of the scene's colour for it (grey, dark or charcoal bowl for the black bowl; cream or off-white mug for the white mug — only when the scene lists exactly one object of that kind); a container word counts as matching an object only if the scene description says the object comes in that container or the object's name contains the word; an object already named elsewhere in the same instruction (its destination, its landmark) is not a candidate; (c) if exactly one scene object qualifies, replace the phrase with that object's name written as rule 3 says; if none or two or more qualify, keep the user's phrase exactly as written and never guess. "dish" as a destination, pushed object or landmark is handled by rule 5, cooking-appliance words by rule 6, and the equivalent pairs listed in rule 12 are left as written.
3. When rule 2, 5 or 6 replaces a noun, write the object's plain product or kind name as one would say it aloud (the ketchup, the orange juice, the alphabet soup, the chocolate pudding, the moka pot, the rack, the bowl, the plate, the mug, the stove), dropping brand names, packaging words (bottle of, can of, carton of, box) and any adjectives the scene description itself uses. Carry over from the user's phrase only a colour word and a position word (black dish -> black bowl; right coffee pot -> right moka pot), writing the scene's basic colour word in place of a shade (grey bowl -> black bowl); drop the user's other adjectives — material, shape, size, finish, state — (wooden stand -> rack, flat dish -> plate, electric hot plate -> stove) unless the scene lists two or more objects of that kind and that adjective is what tells them apart, in which case keep it (small dish -> small bowl); when the replacement is a product name (ketchup, orange juice) drop every adjective (red bottle -> ketchup). Never add a colour word or any other adjective the user did not write, and never change a colour word inside a compound product name (cream cheese stays cream cheese).
4. Never go the other way: never replace a name the user gave with a broader or more generic word, never shorten a product name to its category (ketchup must not become sauce or bottle, orange juice must not become drink or carton, chocolate pudding must not become cup), never introduce dish, hot plate, cup, sauce, drink, bottle, carton, can or container as a substitute for a name, and when rule 2 keeps a generic word because it could not be resolved, keep exactly that word rather than swapping it for a different generic.
5. Handle "dish" (and "flat dish") by its role: when it is the surface something is put or placed on ("put the bowl on the dish", "place it on the dish") or the flat object being pushed or slid ("slide that dish over to the front of the stove"), write "the plate" if the scene lists exactly one plate (keeping any colour or position word the user wrote), and keep "dish" if the scene lists no plate or several plates; when it is a landmark locating the object to be picked up ("the bowl next to the dish", "the bowl on the dish"), write the name of the object that the scene description says the bowl is next to or on (the ramekin, the plate), and keep "dish" if the scene description does not state it; when it is the object being put or picked up, rule 2 applies (exactly one bowl in the scene -> the bowl; several candidates -> keep "dish").
6. Call the cooking appliance "the stove" both when it is being switched on and when it is the place something is put: rewrite hot plate, hotplate, electric hot plate, cooktop, stovetop, hob, range, cooker, griddle, heating element, burner, burners, stove burner and electric stove to "stove"; leave a burner phrase alone when a position word selects one burner among several ("the left burner", "the front burner"), since that selector cannot be carried onto "stove".
7. For any clause whose goal is to turn the stove on — turn on, start, ignite, fire up, power on, light, activate, or a mechanism description such as "turn / twist the (black) knob to start / activate / light the stove" — write exactly "switch on the stove" in that clause's own position (a compound keeps its order: "switch on the stove and put the moka pot on it", "put the moka pot on the stove and switch it on"); apply this only after rule 6 has made the noun "stove" and only when the object is exactly "the stove" (not "the left burner"); do not apply it when the knob phrase carries a position word (the left knob); and do not apply it to turning the stove off — keep the user's off-verb (turn off, switch off, shut off, power off) as written while the other rules still apply to the remaining words.
8. Use the plain action verb only where a sibling verb is evidenced: "pick up" for lift / grab in a "lift X and put / place it ..." frame; "close" for shut / push in (a drawer, a door, the microwave); "push X to" for slide X to / slide X over to (dropping "over"); otherwise keep the user's verb — put, place and set are interchangeable and whichever was written is kept; stack, move, open, take, hold and every other verb stay as written; and never rewrite an off-verb (rule 7).
9. In put / place / pick-up-and-place frames use the plain placement preposition: for a furniture top (cabinet, cupboard, counter, shelf, table, top of the drawer) write "on top of" for atop / up onto / up on / onto; for an object surface (plate, stove, rack, tray, the other bowl) write "on" for onto; for a container (drawer, basket, tray, compartment, slot, caddy, microwave, box) write "in" for into / inside. Leave "on", "in", "on top of", "next to" / "beside" and "to the front / right of" as written, and never touch the preposition inside a phrase that says where an object currently is ("the bowl on the ramekin", "the bowl in the top drawer").
10. When no rule replaces a noun, copy the user's adjectives and descriptive phrases exactly: add none and strip none (silver moka pot, round plate, wooden cabinet, open top drawer of the white cabinet on the left, cream cheese box, black book, brown caddy all stay as written); adjectives are dropped or carried over only as part of a rule 2, 5 or 6 replacement, as rule 3 says.
11. Output a bare lowercase imperative with no terminal punctuation: drop question and politeness wrappers (can you, could you, please, would you mind), desire and declarative frames (i want X on Y, X goes on Y, X should be put on Y -> put X on Y), and filler (just, go ahead and, right up, now); write "the" for "that" / "this"; do not capitalise the first word; change nothing else about the sentence.
12. Leave positional and relational selectors (top / bottom / middle drawer, left / right, front / back / middle, next to, to the right of, in front of, between, on top of it, both) with exactly the words and meaning the user gave: do not add, remove or reword them, because no rewording of a selector has ever helped and a changed selector changes which object or place is meant. The pairs cabinet / cupboard, compartment / slot, top / upper, bottom / lower, back / rear, middle / centre, next to / beside and wooden / wood are understood equally well: they are not resolved by rule 2 and whichever the user wrote is kept.
