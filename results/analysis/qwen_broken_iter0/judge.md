1. **Adherence: zero — the rule was never executed, not once in 40 samples.** Every sampled output is the literal string `Thinking Process:`. That is not a short plain imperative, it contains no objects and no goal; it is the applier's chain-of-thought header captured as if it were the rewrite. So this pass tells us nothing about whether the applier *can* follow this rule — it tells us the qwen applier emits a "Thinking Process:" preamble and the harness's extraction takes that line as the rewrite.

   **Performance: unmeasurable for the rule, and the book number should not be read as if it measured it.** There is no per-rule number, and this pass cannot supply even the book-level one honestly: the measured −2.801 (3.607 vs 6.408) is the cost of replacing every instruction with a contentless label, i.e. it measures how much the proxy relies on instruction text at all, not what this rule does. The one piece of genuine evidence on the rule's merit comes from outside this file: the identical one-rule book applied by the gemini applier produced real rewrites ("Open the oven door.", "Lift the blue bowl.") and measured +0.170 — mildly positive. So the honest reading is high-value-idea / zero-execution on this pass: the failure mode that calls for fixing the application, not the wording's intent.

   **What to do, concretely.** Keep the rule's content and repair the output contract around it, in three steps. First, append an output-format clause the qwen applier cannot misread — e.g. "Output only the rewritten instruction, on a single line. No preamble, no labels such as 'Thinking Process:', no quotes, no explanation." — or put the equivalent in the apply scaffold if the book is meant to stay behavior-only; either way the constraint must reach the applier, because right now the entire book's effect is destroyed before any rule can matter. Second, add a cheap harness guard the numbers here make obvious: refuse to score (and re-draw) any rewrite that is byte-identical across different inputs or shares zero content words with the base and task — that check trips on the second sample and would have saved the whole measurement. Third, treat −2.801 as an invalid anchor for the qwen lane and re-measure iter_00 after the fix; if the distillation loop keeps this number as "the book to beat," the next rulebook will show a huge spurious gain merely by causing qwen to emit words, and every subsequent comparison inherits that distortion. Dropping the rule is not on the table on this evidence, because there is no evidence about the rule here at all. ===SUGGESTIONS===
Canonical-noun restoration — score "put the spatula on the plate in the sink" against the obfuscated base for that task: tells us whether "same objects" should mean same referents (plain category nouns) rather than same noun phrases, since literal preservation ("handheld implement designed for lifting food") reached only ~2.9 on a task family whose clean phrasings sit near 7.
One-visible-attribute addition — "lift the blue bowl" vs "lift the bowl" on the same episodes: the standout +1.88 rewrite in the gemini pass added a color absent from the base, and this separates the grounding-attribute effect from mere de-verbosing.
Deliberate contentless floor — score a fixed neutral string (or empty instruction) per task on purpose: this accident already measured that floor at 0.13–6.25 depending on scene (mean gap 2.8 below real instructions); making it an intentional calibration phrase gives every future rewrite a per-task "value of language" baseline.
Verbatim pass-through — a "return the instruction unchanged" phrasing as a control: with `base_logit_same_draw` false everywhere, same-text-different-draw spread also calibrates measurement noise, which is needed before trusting book deltas as small as gemini's +0.170.
Dataset-register phrasing — lowercase, article-light caption style ("unfold orange cloth from bottom to top", base 6.61) vs polished grammatical imperative ("Unfold the orange cloth from bottom to top.", −0.19): tells us whether the proxy prefers the training-caption register, which would argue against the "plain grammatical imperative" reading of the current rule.
