\begin{abstract}
Companion artifact to ``Rephrase Before You Act: Characterizing and
Mitigating Language Sensitivity in Vision-Language-Action Models''. The
paper charts one significant single-edit swing per task and edit
category; this document charts every significant set the searches found,
with exact p-values. The underlying per-phrase records, including the
phrases themselves, are the two CSV files under \texttt{data/} in this
repository.
\end{abstract}

\section{The Full Set}

A single-edit swing is a set of phrases for the same task that differ by
a minimal edit and whose success rates differ significantly. For $\pi_0$
on SIMPLER Bridge, the search evaluated 105 candidate pairs and 66
survived a two-proportion z test ($z \ge 1.96$); grouped by task and
edit, they form the 35 sets of Fig.~\ref{fig:bridge-full} (n = 72
rollouts per phrase; basket task n = 180). For $\pi_{0.5}$ on LIBERO, the
search evaluated 426 candidate pairs and 115 were significant
($|\Delta| \ge 18$\,pp, $p < 0.05$), forming the 23 sets of
Fig.~\ref{fig:libero-full} (n = 50 per phrase). Unlike the paper's
figures, nothing is curated away here: multi-edit sets and multiple sets
of the same category on the same task are kept.
